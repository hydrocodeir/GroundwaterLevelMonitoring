# گزارش روش‌ها، منابع و فرضیات

این گزارش وضعیت علمی و نرم‌افزاری پروژه را در **۲۱ آبان ۱۴۰۵ (۱۲ نوامبر ۲۰۲۶)** مستند می‌کند. تمرکز آن Sy، سنگ‌کف، حجم معادل آب، نمایش سه‌بعدی و روش برخورد با داده‌های ناقص است؛ اندازه‌گیری صحرایی یا کالیبراسیون جدید انجام نشده است.

- [PDF فارسی](../../output/pdf/HYDROGEOLOGY_METHODS_ASSUMPTIONS_FA.pdf)
- [متن قابل ویرایش](HYDROGEOLOGY_METHODS_ASSUMPTIONS.fa.md)
- [HTML مستقل با فونت‌ها و شکل‌های درون‌فایلی](HYDROGEOLOGY_METHODS_ASSUMPTIONS.fa.html)
- [Manifest و هش SHA-256 داده‌ها و کدهای مرجع](HYDROGEOLOGY_REPORT_MANIFEST.json)

PDF از متن Markdown ساخته می‌شود. تصویرهای نسخهٔ متنی در پوشهٔ `assets` قرار دارند؛ برای جابه‌جایی نسخهٔ متنی، این پوشه را نیز نگه دارید. نسخهٔ HTML به اینترنت یا فونت نصب‌شده روی رایانه نیاز ندارد؛ پیوندهای منابع خارجی تنها هنگام بازکردن آن‌ها به اینترنت نیاز دارند.

## بازتولید

اسکریپت زیر فقط سند محلی را قالب‌بندی می‌کند و محاسبهٔ علمی یا درخواست اینترنتی انجام نمی‌دهد. به Python دارای بسته‌های `Markdown` و `Playwright` و مرورگر Chromium نصب‌شده برای Playwright نیاز دارد. `--qa` با `PyMuPDF` و `Pillow` تمام صفحات را برای بازبینی تصویری در `tmp/pdfs/hydrogeology-qa/` خروجی می‌دهد.

```powershell
python scripts/build_hydrogeology_report.py --qa
```

در محیط فعلی، اسکریپت می‌تواند بستهٔ Markdown را از محیط موجود `.cache/task-venv` نیز بخواند. در محیط دیگر، وابستگی‌های سند را می‌توان چنین آماده کرد:

```powershell
python -m pip install Markdown Playwright PyMuPDF Pillow
python -m playwright install chromium
```

پس از تغییر علمی مدل، نخست متن، اعداد، منابع و تاریخ گزارش را بازبینی و سپس خروجی‌ها را دوباره تولید کنید. Manifest هر بار هش نسخهٔ موجودِ فایل‌های مرجع را ثبت می‌کند؛ بازتولید PDF به‌تنهایی صحت محتوای علمیِ متن قدیمی را تأیید نمی‌کند. Manifest شامل فایل‌های محرمانه، تنظیمات سرویس‌ها یا کلیدهای دسترسی نیست.
